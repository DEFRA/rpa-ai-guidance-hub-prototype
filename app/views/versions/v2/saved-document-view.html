No edit or save controls, and no link into change-review.html or the markdown editor: this is what the document looks like, not a place to work on it. `id`, `documentName` and `version` come from app/routes.js — `version` from app/data/guidance-documents.js, matched by id the same way document-overview.html's own Version tag is, so the two agree. The tag itself uses the same green-1/purple-2 styling already established on find-guidance.html, organic-search.html and document-overview.html. The section content itself is fixed placeholder text local to this template, one set per document id, since it is presentational rather than something anything else in the prototype needs to share. Guided, step-based reading rather than one long scrollable document: each document.sections[].subsections entry is a step (steps is built by flattening sections → subsections below), shown one at a time, with a sidebar to jump to any step directly and Back/Next to move through them in order. There is no "Search for information" box any more — searching a document that only shows one step at a time does not carry over from the old fully-scrollable version. No "Save my place here" or "Currently viewing" at the top any more. A phase caption (govuk-caption-l, "Phase X of 3: ...") sits above each step's own heading instead — baked into every step's own markup rather than a single element kept in sync by JavaScript, so it is never at risk of drifting out of step with whichever one is actually showing — see phaseNames below for how document sections map to the three phases. Below the step, in order: Back/Next, then "Save progress" (renamed from "Save my place here") as a plain-text link rather than a button, then a govukInsetText explaining what it does. Two columns: Content sidebar (independently scrollable if the list is long — .app-document-content__scroll, unchanged) and the step content column, which no longer scrolls independently itself: with one step shown at a time there is nothing long enough inside it to need its own scroll box any more, so the page just scrolls normally if a step runs past the viewport. No Additional information panel for now — removed rather than adapted to update per step. document.sections[].additionalInfo is left in place in case it comes back, it just is not read anywhere on this page any more. Each section in the sidebar is collapsed by default: its own heading is also a step link, to that section's first step, so clicking it is never a dead end — its subsections are hidden behind a separate chevron toggle next to it rather than shown automatically.
