{# The formatting toolbar and textarea half of the simpler markdown editor. Split out from partials/markdown-editor-content.html so a page can lay this out separately from the Content list next to it (see partials/markdown-editor-nav.html) — guidance-document-edit.html uses the two independently; markdown-editor-content.html still pairs them side by side for change-review.html. The toolbar buttons are scoped to their own textarea via data-target rather than assuming there is only one editor on the page. Each wraps or prefixes the current selection; with nothing selected, it inserts its own placeholder text instead and selects just that, so typing replaces it — setRangeText() rather than the full editor's execCommand('insertText') dance, which exists there to keep the browser's native undo stack working over a 100-page document. That does not matter for a handful of toolbar clicks on fixed placeholder text. Included rather than a macro, since the textarea's placeholder markdown is large, fixed body text rather than something a caller passes in. #}
